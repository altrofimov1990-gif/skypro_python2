# Проект автоматизации тестирования



## Описание



Проект содержит автоматизированные тесты для проверки функциональности:

- Калькулятора с задержкой (slow-calculator)

- Интернет-магазина SauceDemo





## Требования (в проекте используются следующие технологии)



- Python 3.8+

- pytest

- selenium

- allure-pytest



## Форматирование кода



- Код форматируется в соответствии стандартам PEP8



flake8 lesson_10/



## Установка



1. Клонировать репозиторий

2. Установить зависимости:



pip install -r requirements.txt



## Запуск тестов (предворительно перейти lesson10)



pytest tests/



## Запуск тестов с формированием Allure отчета



pytest tests/ --alluredir=allure-results



## Запуск просмотра с формиррованного отчета Allure



allure serve allure-results 



##  Выход (Завершить выполнение пакетного файла)



Нажмите Ctrl+C для выхода.
